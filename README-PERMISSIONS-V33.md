# صلاحيات admin / manager / user

- `admin`: صلاحية كاملة، ويستطيع اختيار أي موظف في سجل التقارير وسجل الحركات.
- `manager`: يرى ويعدل بيانات الموظفين التابعين له فقط، وتظهر له أسماء فريقه فقط.
- `user`: يرى ويعدل ملفاته وحركاته فقط، ولا تظهر له قائمة موظفين.

يُحدَّد التابعون من عمود `mgr` في ورقة `Employees`. يجب أن يطابق اسم المدير
في هذا العمود اسمه في ورقة `Users` حرفياً. يضيف النظام عمودي
`reportOwnerId` و`reportOwnerName` إلى `Reports` تلقائياً عند أول حفظ.

بعد رفع الملفات، انسخ `code.gs.txt` إلى Google Apps Script وانشر نسخة جديدة
من Web App، ثم سجّل الخروج والدخول من جديد.
