# V30 - Festival Movement / Sales / Expenses

- عند الضغط على «إرسال صافي المحصلة إلى المبيعات» تظهر نافذة لاختيار التقرير المستهدف.
- يتم تسجيل صافي المبيعات في `sales` باستخدام `reportId` للتقرير المختار.
- يتم تسجيل نفس الكميات في `festivalMovement` كعملية `مبيعات` وبنفس `reportId`.
- سعر المادة يأخذ من مبيعات التقرير المختار عند وجود المادة فيه، وإلا من `Products` كقيمة احتياطية.
- عند حفظ أو تعديل أي تقرير، تُرسل كميات `expenses` إلى `festivalMovement` كعملية `صرف`، مع استبدال حركة الصرف السابقة لنفس التقرير عند التعديل لمنع التكرار.
- لم يتم حذف أي قسم من الموقع أو تغيير وظائف المبيعات/المنافس/الباركود/الكاش الحالية.
